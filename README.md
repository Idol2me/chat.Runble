# Runble

**A chat from gamers, by gamers. Light as a feather.**

Runble is a minimalist chat app. Messages, voice and screen sharing, with nothing else in the way.

## Features

- **Messages:** channels and replies. Nothing else.
- **Voice:** start a call in one click.
- **Screen sharing:** show a single window or your whole screen while you keep talking.
- **Minimal by design:** no feeds, no noise, no pop-ups asking for your attention.
- **Open source:** read the code, report bugs and help improve it.

## Download

Runble is currently available for **Windows only**.

1. Go to the [latest release](https://github.com/Idol2me/chat.Runble/releases/latest).
2. Download the Windows file from the **Assets** list.
3. Run it.

Only download Runble from this repository. If you got it from somewhere else, delete it and download it again from the link above.
